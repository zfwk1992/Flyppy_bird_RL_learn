# 01 · 强化学习基础

用本项目的 Flappy Bird 当例子，把 RL 的基本概念过一遍。
每个概念都指向仓库里对应的代码。

---

## 1. 问题设定：MDP

强化学习研究的是**序贯决策**：智能体反复地观察 → 行动 → 得到奖励。
标准形式是马尔可夫决策过程（MDP），五元组 `(S, A, P, R, γ)`。

对上本项目：

| 符号 | 含义 | 本项目 | 代码 |
|------|------|--------|------|
| `S` | 状态空间 | 最近 4 帧 80×80 二值图，即 `{0,255}^(4×80×80)` | `FrameStack` |
| `A` | 动作空间 | `{0=不动, 1=扇翅}` | `DuelingDQN` 输出 2 维 |
| `P` | 转移概率 | 游戏物理（确定的）+ 管道随机生成 | `FlappyEnv.step` |
| `R` | 奖励函数 | 过管道 +1，撞死 −1，存活 0 | `FlappyEnv.step` |
| `γ` | 折扣因子 | 0.99 | `CONFIG['gamma']` |

### 马尔可夫性

MDP 的核心假设是**马尔可夫性**：下一个状态只依赖当前状态和动作，
与更早的历史无关。

```
P(s_{t+1} | s_t, a_t, s_{t-1}, a_{t-1}, ...) = P(s_{t+1} | s_t, a_t)
```

**单帧画面不满足马尔可夫性**，因为看不出小鸟的速度 —— 同一张图，
小鸟可能在上升也可能在下落，最优动作完全不同。

这就是要叠 4 帧的原因：有了连续几帧，速度（一阶差分）甚至加速度
（二阶差分）都能被卷积网络推断出来。详见 [05 · 环境与观测](05-environment.md)。

> **这是 RL 里第一个常见错误**：把一个非马尔可夫的观测当状态用。
> 网络会显得"学不动"，但根源不在网络。

## 2. 回报：我们到底在最大化什么

单步奖励 `r_t` 只反映眼前。RL 真正优化的是**回报**（return）——
从当前时刻起的折扣奖励总和：

```
G_t = r_t + γ·r_{t+1} + γ²·r_{t+2} + γ³·r_{t+3} + ...
```

### γ 是什么意思

`γ ∈ [0,1)` 是折扣因子，本项目取 **0.99**。它有两重含义：

1. **数学上**：保证无穷级数收敛。奖励有界时，`G_t ≤ r_max/(1−γ)`。
2. **行为上**：控制智能体看多远。有效视野约为 `1/(1−γ)` 步。
   γ=0.99 → 约 100 步；γ=0.9 → 只有 10 步。

**本项目里 γ 作用在"决策"上，不是"帧"上。** 一次决策 = 4 帧，
所以 γ=0.99 对应约 100 次决策 = 400 帧的视野。管道间隔约 7.2 次决策，
所以视野覆盖约 14 根管道 —— 足够了。

> γ 调小会怎样？智能体会变得"短视"：它看不到 12 次决策之后的那根管道，
> 于是学不会为通过管道而提前调整高度。

### 回报的上限

本项目的奖励尺度下（过管道 +1，撞死 −1），一个**永不死亡**的策略，
其 Q 值会趋向：

```
Q_max = γ^12.5 / (1 − γ^7.2) ≈ 12.6
```

其中 12.5 是管道从生成到得分的决策数，7.2 是相邻管道的决策间隔。

这个数在诊断时很有用：**低分段有经验规律 `Q ≈ 0.9 × 已过管道数`，
但 Q 会饱和在 12.6 左右，不会无限涨**。看到 Q 冲到几百，说明发散了。
`eval.py --q-stats` 会打印这个对照。

## 3. 策略与价值函数

**策略** `π(a|s)`：在状态 s 下选动作 a 的规则。目标是找到最优策略 `π*`，
使期望回报最大。

### 两种价值函数

**状态价值** `V^π(s)`：从 s 出发、follow π 能拿到的期望回报。

```
V^π(s) = E_π[ G_t | s_t = s ]
```

**动作价值**（Q 函数）`Q^π(s,a)`：在 s **先做 a**，之后再 follow π。

```
Q^π(s,a) = E_π[ G_t | s_t = s, a_t = a ]
```

### 为什么 DQN 学 Q 而不是 V

因为**有了 Q 就能直接选动作**，不需要环境模型：

```python
action = Q(s).argmax()
```

而只有 V 的话，要选动作就得知道"做了 a 之后会到哪个 s'"，
也就是需要转移模型 `P`。本项目里我们不建模游戏物理，所以学 Q。

代码：[`flappy/agent.py: Agent.act()`](../../flappy/agent.py)

```python
@torch.no_grad()
def act(self, stack_uint8):
    t = torch.from_numpy(stack_uint8).unsqueeze(0).to(self.device)
    return int(self.online(t).argmax(1).item())
```

## 4. Bellman 方程

价值函数满足递归关系。最优 Q 函数的 Bellman 最优方程：

```
Q*(s,a) = E[ r + γ · max_{a'} Q*(s', a') ]
```

读法：**"现在这一步的价值 = 立即奖励 + 折扣后的、下一步最好动作的价值"**。

这个方程是所有 Q-learning 类算法的地基。它给出一个迭代算子 `T`：

```
(T Q)(s,a) = E[ r + γ · max_{a'} Q(s', a') ]
```

可以证明 `T` 在无穷范数下是**压缩映射**（压缩系数 γ），
所以反复施加 `T` 会收敛到唯一不动点 `Q*`。

> ### 这里藏着旧管线最深的一个 bug
>
> 压缩映射定理的前提是 **T 是一个固定的算子**。
>
> 旧网络的目标网络带 BatchNorm 且长期处于 train 模式，于是
> `Q_target(s')` 的取值依赖于"这一批里碰巧还有哪些别的样本"。
> 算子 T 每一批都在变 —— **不动点根本不存在**，谈不上收敛。
>
> 详见 [00 · 为什么之前不收敛](00-why-it-failed.md) 第三节。

## 5. 时序差分学习

怎么在不知道 `P` 和 `R` 的情况下逼近 `Q*`？用**采样**代替期望。

拿到一条真实经验 `(s, a, r, s')`，Bellman 方程给出一个**目标值**：

```
y = r + γ · max_{a'} Q(s', a')        # s' 非终止
y = r                                  # s' 终止
```

当前估计是 `Q(s,a)`，两者之差叫 **TD 误差**：

```
δ = y − Q(s,a)
```

学习就是让 `Q(s,a)` 朝 `y` 挪一点。表格情形下：

```
Q(s,a) ← Q(s,a) + α·δ
```

神经网络情形下，就是对 `δ` 做梯度下降。代码：

```python
# flappy/agent.py: Agent.learn()
q_sa = self.online(s).gather(1, a.unsqueeze(1))       # Q(s,a)
with torch.no_grad():
    a_star = self.online(s1).argmax(1, keepdim=True)  # Double DQN
    q_next = self.target(s1).gather(1, a_star)
    y = r.unsqueeze(1) + cfg['gamma'] * q_next * (~d).unsqueeze(1)
loss = F.smooth_l1_loss(q_sa, y)
```

注意 `* (~d)`：终止状态没有未来，`y` 就等于 `r`。
**这一项写错（比如 done 标记丢失）会让网络以为死了还能继续拿奖励** ——
旧管线丢弃了 75% 的 terminal，正是栽在这里。

### 为什么用 Huber 而不是 MSE

`F.smooth_l1_loss` 是 Huber 损失：误差小时是平方，误差大时是线性。

RL 的目标值 `y` 本身是估计出来的、带噪声的，偶尔会有很离谱的 TD 误差。
MSE 对离群值的梯度是 `2δ`，会被单个坏样本主导；Huber 在 `|δ|>1` 时梯度
恒为 ±1，天然限幅。

> 这也是**为什么奖励尺度重要**。Huber 的拐点固定在 δ=1。
> 旧管线奖励是 +20，几乎每个含管道的样本都落在线性区，
> 梯度被常数化，"过了 1 根"和"过了 5 根"产生一样的梯度。
> 新管线把奖励归一化到 ±1，拐点就落在了正确的位置。

## 6. On-policy vs Off-policy

- **On-policy**：只能用「当前策略」产生的数据学习（如 SARSA、A2C、PPO）。
- **Off-policy**：可以用「别的策略」产生的数据学习（如 Q-learning、DQN）。

Q-learning 是 off-policy 的，因为目标里用的是 `max_{a'} Q(s',a')`，
即"假设之后按最优策略走"，与实际产生这条数据的策略无关。

**这一点非常关键**，它是经验回放能成立的前提：缓冲区里存着几十万条
用各种旧策略（不同 ε 下）产生的经验，off-policy 才允许我们拿它们训练当前网络。

它还允许我们**自由设计行为策略**。本项目就利用了这一点：

```python
def sample_random_action(cfg):
    """随机动作按 p_flap≈0.2 采样，而非均匀的 0.5。"""
    return 1 if random.random() < cfg['eps_random_flap_prob'] else 0
```

均匀随机（p=0.5）会把鸟顶死在天花板上，收集到的经验毫无价值。
改成 0.2 只影响行为策略，**不影响 Q 学习的正确性**。
详见 [07 · 探索策略](07-exploration.md)。

## 7. 本项目的完整 MDP 图景

```
       ┌─────────────────────────────────────────┐
       │            环境 FlappyEnv                │
       │  物理: 重力 +0.5/帧, 扇翅 velY = −5      │
       │  奖励: 过管道 +1, 撞死 −1, 存活 0        │
       └───────┬─────────────────────▲───────────┘
               │ s' (80×80 二值帧)   │ a ∈ {0,1}
               │ r, done             │ (窗口内重复 4 帧)
               ▼                     │
       ┌─────────────────────────────┴───────────┐
       │            智能体 Agent                  │
       │  帧栈: 最近 4 次决策的末帧 → (4,80,80)   │
       │  策略: ε-贪婪                            │
       │        ε 概率随机 (p_flap=0.2)           │
       │        1−ε 概率 argmax Q(s,·)            │
       │  学习: Double-DQN + Huber                │
       └─────────────────────────────────────────┘
```

## 小结

| 概念 | 一句话 | 本项目 |
|------|--------|--------|
| MDP | 状态、动作、转移、奖励、折扣 | 4 帧图 / 2 动作 / γ=0.99 |
| 马尔可夫性 | 未来只依赖现在 | 靠叠 4 帧才成立 |
| 回报 `G_t` | 折扣奖励和，真正的优化目标 | 上限约 12.6 |
| `Q(s,a)` | 先做 a、之后最优的期望回报 | 网络的 2 个输出 |
| Bellman | `Q* = r + γ max Q*` | `learn()` 里的 `y` |
| TD 误差 | `y − Q(s,a)`，学习信号 | `train.csv` 的 `td_abs_mean` |
| Off-policy | 能用旧策略的数据学 | 经验回放的前提 |
